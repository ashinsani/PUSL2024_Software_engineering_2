# PUSL2024 – Software Engineering 2

**Software Engineering 2** project developed as part of the PUSL2024 curriculum.

---


## Project Overview

This repository contains the **Software Engineering 2** project for PUSL2024. The goal is to apply software engineering principles — from requirement gathering and system modeling to implementation, testing, and documentation — in order to build a well-structured, maintainable, and modular application.

---

## Features

Here are the core features of the project:

- **User Registration & Authentication**  
- **Role-Based Access Control** (e.g., Admin, Regular User)  
- **CRUD Operations** for key entities (Users, Items, Tasks, etc.)  
- **Reporting Module**: Generate summaries / analytics  
- **Activity Logging / Audit Trail**: Track user actions  
- **User Interface**: Web-based frontend for interacting with the system  
- **Automated Tests**: Unit tests, integration tests  

---


## Technologies Used

- **Programming Language(s)**: Java.  
- **Framework(s)**: Spring Boot.  
- **Database**: MySQL.  
- **Build Tools**: Gradle.  
- **Version Control**: Git (GitHub)
